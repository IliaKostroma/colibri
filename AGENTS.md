## 0. TL;DR за 30 секунд

- **COLIBRI** — таск-менеджер с **голосовым вводом** и AI-обработкой текста. Личный инструмент Ильи, живёт как веб (Netlify) + десктоп (Electron).
- Поток: наговорил голосом → текст в поле → по кнопке «улучшить» / «перевести» через OpenAI или OpenRouter → сохранил как задачу.
- **Стек:** vanilla JS (без фреймворков) + Vite + Supabase (auth + БД) + Electron. `src/app.js` — 1419 строк, всё UI-состояние в нём.
- **Хранение:** offline-first — локальный кэш в localStorage + фоновая синхронизация с Supabase каждые 15 с.
- **Живой деплой:** GitHub `IliaKostroma/colibri` → автодеплой Netlify (`netlify.toml`, SPA-редирект).
- **Проект — самостоятельный git-репозиторий внутри волта.** Волт его НЕ трекает (строка `colibri/` в `.gitignore` волта). Коммитить надо **изнутри** `colibri/`.

## ⚠️ 1. Первое, что нужно знать: тестам нельзя верить

`npm test` сейчас печатает **«41 passed»** и два упавших *файла*. Это ловушка — не читай это как «всё зелено».

Что происходит на самом деле:

1. `src/services/supabase.js:15` дёргает `window.matchMedia` (детект PWA) прямо на уровне модуля. В `src/test-setup.js` этого стаба нет → `storage.test.js` и `import-dates.test.js` **падают на импорте**, до сбора тестов. 27 тестов внутри просто не считаются в статистике.
2. Если добавить стаб `matchMedia` — собирается **68 тестов, 17 падают**. Тесты устарели по архитектуре: `storage.test.js` проверяет синхронный localStorage-API (`saveApiKey`/`getTasks` без `await`), а `storage.js` давно ходит в Supabase и всё асинхронно.

**Вывод для агента:** самый большой сервис проекта (`storage.js`, 829 строк) фактически **без покрытия**. Не трогай логику хранения «под прикрытием зелёных тестов» — их нет. Задача на починку — `T1` в `PROJECT_STATE.json`.

## 3. Как запустить

```bash
npm install          # если node_modules нет
npm run dev          # веб: http://localhost:5173
npm test             # ⚠️ читай раздел 1 прежде чем верить результату
npm run build        # прод-сборка в dist/
npm run electron:dev # десктоп, dev-режим (грузит localhost:5173)
npm run electron:build:mac  # сборка .dmg/.zip в release/
```

Нужен `.env` в корне (в git не лежит, см. `.env.example`):

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

Голосовой ввод — **Web Speech API**, работает только в Chrome/Safari, язык захардкожен `ru-RU` (`speechRecognition.js:75`). В Firefox не заведётся.

## 4. Карта архитектуры

```
index.html                      # вся разметка: header, main, модалка настроек, модалка авторизации
src/
├── app.js                      # 1419 строк: состояние, весь UI, все обработчики, рендер задач
├── styles/main.css             # 1167 строк, CSS-переменные из DESIGN-SYSTEM.md
└── services/
    ├── supabase.js             # клиент Supabase + кастомный storage для PWA-режима
    ├── auth.js                 # signUp/signIn/signOut + get/saveUserSettings (таблица user_settings)
    ├── storage.js              # 829 строк: offline-first кэш задач + синк + импорт/экспорт (JSON и Markdown)
    ├── speechRecognition.js    # обёртка Web Speech API, ru-RU
    ├── openai.js               # improveText / translateToEnglish, дефолт gpt-3.5-turbo
    └── openrouter.js           # то же через OpenRouter, дефолт google/gemini-2.0-flash-001
electron/main.cjs               # поднимает express на 127.0.0.1:45789, отдаёт dist/, просит доступ к микрофону
```

**Поток данных (задачи):**
`app.js` → `storage.js` → локальный кэш `colibri_tasks_cache` в localStorage (мгновенный отклик) → очередь операций → `syncInBackground()` в Supabase каждые 15 с. Все сетевые вызовы обёрнуты в `withTimeout` (8 с) — это защита от вечной загрузки на мобильном.

**Поток данных (настройки):** ключи API, провайдер и модель хранятся **не локально, а в Supabase** `user_settings` (по `user_id`). То есть без авторизации настроек нет.

**Таблицы Supabase:** `tasks`, `user_settings`.

## 5. Конвенции и подводные камни

- **Никаких фреймворков.** Vanilla JS, прямые обращения к DOM через закэшированные ссылки в `elements` (`cacheElements()` в `app.js:1242`). Не тащи React/подобное без явного решения Ильи.
- **`app.js` — монолит.** Новая функция = экспортируемая функция + запись в `elements` + привязка в `bindEvents()`. Держи этот порядок, иначе элемент будет `null` в проде и молча ничего не сделает.
- **`saveUserSettings()` возвращает `{success, error}` — и все вызывающие его сейчас этот результат выбрасывают.** Если пишешь новую настройку, проверяй результат, иначе провал сохранения будет молчаливым (задача `T2`).
- **Ключи API вводит пользователь**, они лежат в Supabase в открытом виде — защищает только RLS. В бандл не собираются, в git не попадают. Из `VITE_*` в бандл инлайнится только Supabase URL и **anon**-ключ — это by design.
- **Язык интерфейса и промтов — русский.** Системные промты `IMPROVE_PROMPT` / `TRANSLATE_PROMPT` дублируются в `openai.js` и `openrouter.js` — правишь один, правь второй.
- **Markdown-импорт хрупкий** — эмодзи-метки цветов и метаданные `*(выполнено: …, id: …)*` парсятся регулярками. Прежде чем менять формат, читай `IMPORT-EXPORT-TEST.md`.
- **Обсидиан рядом.** Папка лежит внутри волта, но это код, а не заметки: не превращай `.md`-файлы проекта в вики-заметки с фронтматтером, они читаются людьми и агентами как проектная документация.

## 6. Как коммитить

```bash
cd colibri            # ВНУТРИ проекта, не из корня волта
git status
git add … && git commit
git push              # → GitHub → автодеплой Netlify
```

⚠️ **`cd` нужен в КАЖДОЙ команде, а не один раз.** В Claude Code рабочая директория сбрасывается между вызовами Bash, поэтому `git push` без `cd` уедет в репозиторий волта. Это уже случилось 27.07.2026 — см. `DEVLOG.md`.

Remote — по SSH (`git@github.com:IliaKostroma/colibri.git`); по HTTPS пуш требует пароля и падает.

Волт (`MotherVault/.git`) папку `colibri/` игнорирует целиком. Не пытайся коммитить проект из корня волта — получишь gitlink-заглушку.

**Пуш = деплой в прод.** У Netlify стоит автодеплой с `main`. Перед пушем проверь как минимум `npm run build`.
